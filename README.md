# Morph OptiFine Compat

[English] | [简体中文](./README_zh.md)

<p align="center">
  <img src="resources/Logo.png" width="256">
</p>

Makes [Morph](https://www.curseforge.com/minecraft/mc-mods/morph) compatible with [OptiFine](https://optifine.net/home) on 1.7.10 Forge.

Supports any version of Morph and its forks.

> This is a **client-side mod**. Only needs to be installed on the client; the server does not need it.
